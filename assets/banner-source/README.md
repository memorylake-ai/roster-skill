# README banner source

`banner.html` is the source of `../banner-light.png` and `../banner-dark.png` (1280×400, rendered at 2×).
Colors and type follow the Roster desktop console (Inter, Geist Mono, canvas `#f5f6f8` / `#0d0f13`, brand blue `#1f5ad6`).

To re-render, open `banner.html` in a headless Chromium at a 1280×400 viewport with device scale factor 2 and screenshot `#stage`;
append `?dark` to the URL for the dark version. The page loads Inter and Geist Mono from Google Fonts.
